MODULE 0413 / 85
The name

MCP = Model Context Protocol

A name that describes exactly what it does.

02 · WHAT IS MCP
M

Model

The AI application or model that needs context and capabilities.

C

Context

Information and operations from systems outside the model.

P

Protocol

A shared set of rules for how the two sides communicate.

MCP is an open standard that defines how AI applications communicate with external systems through MCP servers.

6.1 · OAuth

What is OAuth?

An authorization mechanism for permitted access.

06 · OAUTH
OAuth allows one application to access permitted information or operations in another application without requiring the user to share their password directly.
🔑

No password sharing

The connected app never sees your GitHub password.

🎯

Permitted access only

Access is limited to what you approve.

🧾

Token-based

The connector uses an access token for operations.
