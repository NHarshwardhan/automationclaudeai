MODULE 0411 / 36
The three roles

Host, Client and Server

Office analogy: an employee asks a communication desk to contact the right department.

04 · ARCHITECTURE
🏢

MCP Host

Application where the AI experience runs and which manages MCP connections. Office = the company. Examples: Claude Desktop, Claude Code, Claude.ai. Claude.ai is a Host because it provides the AI experience and manages connections.

🔄

MCP Client

Component that establishes communication with an MCP Server. Like a mobile banking app's communication component sending requests to the banking server. Claude's Client handles communication; Claude decides what is needed.

🏬

MCP Server

Connection point that exposes capabilities: Gmail department, Drive department, GitHub department. It can run locally on your computer or remotely on another system.

HOST
The application managing the AI experience and MCP connections.
Example: Claude.ai.

Authentication

Why OAuth? What OAuth is

Confidential data needs proof of identity and permission.

06 · OAUTH
Bank analogy: an employee asks for an account statement. The bank will not provide confidential information just because someone asks — identity must first be proven. The same applies to Gmail or any private application.
OAuth is an authorization mechanism that lets one application access selected information or perform selected actions in another application without sharing the user's password with that application.
🪪

Office analogy: a temporary access card

PermissionMeaning
Read emailsCan view permitted emails.
Search emailsCan search permitted email data.
Send emailsCan send emails if authorized.
Modify emailsCan make permitted changes.
Permission scoping limits access to what is needed: an office assistant may read documents but not delete them. It protects private information, reduces unnecessary access, limits damage if compromised, and gives users control.
Note: OAuth is about authorization, not simply login. Logging in establishes who you are; authorization determines what the connected application may access.

Call trace

What a call trace shows

The sequence of tool calls and their results during a conversation — the activity history of the office assistant.

09 · MULTI-TOOL
①

Which tool was called first, and which next?

③

What input was passed to each call?

⑤

How did one output feed the next operation?

②

What output was returned each time?

🔗

Where did a result become the next input?

👀

A trace turns “Claude gave an answer” into a debuggable sequence of steps.

Important: chaining does not mean all tools execute simultaneously. Some workflows require one tool's result before the next call. Claude may not always use the exact same sequence — it depends on the tools available and the task.

Graceful degradation:

Honest handling when a service is unavailable.

MODULE 0433 / 36
Definition + scenarios

Graceful degradation in action

Handle unavailability sensibly — do not pretend everything works.

10 · DEGRADATION
Office analogy: the Gmail department is closed for maintenance. You ask, “Find my latest email from HR.” A responsible assistant says, “I cannot access Gmail right now because the connection is unavailable.” It does not invent an email or pretend to have searched.
SCENARIO 1 · CONNECTED
User: “Find my latest HR email.”
Claude uses Gmail tools and returns matching information.
Available.
vs
SCENARIO 2 · DISCONNECTED
User: “Find my latest HR email.”
Claude explains Gmail is unavailable and asks you to reconnect or try later.
Unavailable.
That is graceful degradation.
MODULE 04 · WHAT IS MCP & CLAUDE CAPABILITIES34 / 36
Under the hood

Technical behavior and the honest-failure caveat

Depending on how the connector is disconnected:

10 · DEGRADATION
🔌

The MCP Client may no longer communicate with the server.

⚠

The server may return a connection or execution error.

📭

The connector may no longer expose its tools to Claude.

💬

Claude may explain that it cannot access the external information.

Important: graceful degradation does not mean Claude can continue performing the disconnected operation. It means it handles the failure honestly and appropriately.
