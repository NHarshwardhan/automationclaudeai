MODULE 0511 / 26
The problem + definition

What is tool filtering?

An employee has access to 50 office operations — but your job is product management.

03 · TOOL FILTERING
🚫

You do not need

Payroll operationsEmployee salary informationRecruitment operationsFinancial approvals

Giving access to everything creates unnecessary complexity and potential security risks.

✅

You only need

Product-related operations. Tool filtering means controlling which MCP tools are made available to Claude for a particular task or workflow.

Product MCP Server toolPurposeNeeded to inspect products?
list_productsRetrieve products.Yes
create_productCreate products.No
update_productUpdate products.No
delete_productDelete products.No
run_testsRun automated tests.No
A developer who only needs to inspect products needs list_products — not the rest.
MODULE 05 · ADVANCED MCP CONFIGURATION12 / 26

Why is tool filtering important?

Five practical benefits.

03 · TOOL FILTERING
1

Reduces availability

Fewer unnecessary tools are exposed.

2

Clearer selection

Tool choice is easier to understand.

3

Fewer accidents

Helps reduce accidental operations.

4

Controlled access

Supports controlled capability access.

5

Focused workflow

Keeps work on relevant operations.

Expose what the task needs — not everything the server can do.

More error types

Validation and timeout errors

Invalid input and slow operations.

04 · ERRORS
✅

C · Validation errors

Claude sends invalid input to an MCP tool. Suppose create_product requires:

Product nameSKUCategoryPriceStock

But Claude sends a negative price. The server should reject it:

server response
Error: Price must be a positive number.
⏱

D · Timeout errors

A tool takes longer than the allowed execution time.

For example, run_tests executes the Product Management API test suite. If test execution takes too long, the operation may time out.

A timeout is a controlled stop — not a silent failure.
MODULE 05 · ADVANCED MCP CONFIGURATION16 / 26
Timeout

What is a timeout?

The maximum time an application allows an operation before stopping or reporting it took too long.

04 · ERRORS
Analogy: ask someone to prepare a report within one minute. If it is not ready after one minute, you stop waiting and investigate. That is the purpose of a timeout.
POOR HANDLING
Crash, hang indefinitely, or return misleading information.
vs
GRACEFUL HANDLING
Stop at the limit, report the problem, explain what happened.
Connects back to graceful degradation.
Handle the error honestly — do not pretend the operation succeeded.
